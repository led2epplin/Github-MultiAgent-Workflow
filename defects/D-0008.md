## 재현
HEAD 가 A 인 checkout 의 `engine/WORKFLOW.md` 를 고치고(커밋 안 함) 빈 소비 저장소에서 `engine.ref=A`, `mode=docs`, `MAWF_ENGINE_SRC=<checkout>` 으로 동기화. 고친 문서가 복사되고 `ENGINE_REF` = A.

## 원인
`MAWF_ENGINE_SRC` 는 작업 트리를 그대로 소스로 쓰고 HEAD 만 ref 와 비교했다.

## TC
`bash tests/defects/D-0008.sh <임시폴더> [대상 엔진 저장소]` — HEAD = A + 미커밋 변경 checkout · HEAD = B(A 를 이력에 가짐) checkout 을 MAWF_ENGINE_SRC 로, ref A → `.mawf/WORKFLOW.md` = 커밋 A 내용, 기록 = 「A docs」, 미커밋 변경 없음.

## 수정
해시 ref 이고 `MAWF_ENGINE_SRC` 가 git 저장소면 작업 트리 대신 그 checkout 에서 커밋을 로컬 fetch(`git init` + `fetch --depth 1 <checkout> <sha>` + checkout) 해 적용 — 커밋 트리를 내보내는 것과 같다. 미커밋 변경·다른 HEAD 와 무관하게 고정한 커밋만 들어간다(그 커밋이 checkout 에 없으면 받지 못함 안내).
