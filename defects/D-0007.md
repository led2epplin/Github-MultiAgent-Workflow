## 재현
커밋 B 를 내보낸 git 메타데이터 없는 폴더를 `engine.repo` 또는 `MAWF_ENGINE_SRC` 로, `engine.ref` 는 커밋 A 의 해시. 동기화하면 B 의 파일을 복사하고 「갱신」.

## 원인
`head_sha()` 가 빈 값(git 아님)을 돌려주면 커밋 확인을 건너뛰었다(`if sha and got and got != ref`).

## TC

## 수정
해시 ref 면 받은 판의 커밋이 ref 와 같을 때만 적용(`got != ref` → 「동기화 실패 … 기존 파일 그대로」). `head_sha` 는 src 가 git 저장소 뿌리일 때만 값을 낸다(다른 저장소 안의 폴더는 확인 불가).
