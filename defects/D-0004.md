## 재현
늘 실패하는 TC(exit 23)를 단 defect 티켓에 `build/tk done` 또는 `build/tk move <T> done` → 그대로 done. 손으로 tickets/done 에 옮긴(reviewed_by·fixed_in 빈) defect 도 `build/validate --all` 이 통과.

## 원인
1.1.0 에서 close(tc 재실행·reviewed_by)를 `tk close` 로 만들었지만, 예전 경로(cmd_done·cmd_move)는 type 을 보지 않았고 validate 는 done 상태 defect 의 close 흔적을 검사하지 않았다.

## TC
`bash tests/defects/D-0004.sh <임시폴더> [대상 엔진 저장소]` — 설치한 빈 저장소에서 위 두 경로 거절, done 의 빈 defect 에 validate 오류(reviewed_by·fixed_in), 대조로 resolve → close 경로는 통과.

## 수정
`tk done`·`tk move … done` 은 defect 면 거절(안내: `tk close`), `validate` 는 tickets/done 의 defect 에 fixed_in·reviewed_by 가 비면 오류(engine/build/tk·validate).
