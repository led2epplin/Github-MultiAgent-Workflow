# 장기기억 색인

대화에서만 오간 중요한 정보(사용자 지시·정정·진단·계획)를 **그 턴에** 여기 문서로 남기고 커밋·push 한다 — 다음 세션·러너·검수자가 같은 설명을 다시 듣지 않게.
- 대화형 세션: SessionStart 훅이 이 색인을 주입한다 → 필요한 문서만 연다.
- 작업자(러너): inputs 만 읽는다 → 티켓 발주 때 관련 문서를 inputs 에 넣는다.
- 바뀐 줄에는 날짜. 비공개로 하라는 내용은 쓰지 않는다.

| 문서 | 내용 | 언제 읽나 |
|---|---|---|
| (예) 사용자지시.md | 사용자가 직접 준 상시 지시 | 모든 세션·티켓 발주 전 |
