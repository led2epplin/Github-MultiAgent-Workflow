# <프로젝트 이름> — 검수자 규칙 (Codex / 검수 에이전트 공통)

PR 은 작업 티켓 1장의 산출물이다. 검수자는 **지적만** 하고 고치지 않는다. 검수 입력은 PR diff 의 산출물 + 아래 검사식뿐이다. 작업자의 notes·대화·추측은 근거가 아니다.

## Code Review Rules

### P0 = 오류 (하나라도 있으면 반려)
<!-- 도메인 검사식을 여기에 번호를 붙여 적는다. 예: 원문 불일치, 내부 모순, 스키마 위반, 숫자 오류 -->
1. 스키마 위반 — 머리말 필수 항목 누락, `id` 중복, 파일명 ≠ id.
2. 내부 모순 — 같은 PR 안의 산출물끼리 서로 다른 말을 한다.

### P1 = 권고 (반려하지 않지만 보고)
- 모호한 문장, 1줄짜리 설명, 근거 없는 단정.

### 확인 = 작성자가 `[확인]` 으로 표시한 곳의 목록 (판정하지 않고 세기만)

### 출력 형식 (고정)
```
오류 n / 권고 m / 확인 k
[P0-1] path/file.md:L23 — 「…」 ≠ 근거 「…」
[P1-1] …
[확인] path/file.md:L9 …
```
한 줄에 하나, 파일:줄, 인용 원문 포함. 요약·칭찬·총평은 쓰지 않는다.
